# 🍽️ Flavour-Delights 
### *An Online Food Delivery Website*

**FlavourDELIGHTS** is a web project showcasing a stylish, responsive food-themed interface built entirely with **HTML and inline CSS**. Created as a group collaboration, the site highlights a range of delightful dishes, trending recipes, and popular restaurants — all within an intuitive, image-rich layout. No backend logic is included.

---

## 🚀 Features

- ✅ Fully static site using **HTML & Inline CSS**
- ✅ Responsive layout for desktop and mobile
- ✅ Visually engaging, image-heavy design
- ✅ Built through collaborative workflow

---

## 💡 How to Use

No installation needed — it's a fully static website!

- Open `index.html` in any modern web browser.
- Navigate through the following pages:
  - `start.html` → `loginn.html` → `success.html` → `food.html` → `ord.html` → `done.html`
  - Learn more via `a.html` (About) and `cont.html` (Contact)

All pages are built with *pure HTML and Inline CSS*, making it easy to view, modify, or extend the project without requiring any backend or server setup.
